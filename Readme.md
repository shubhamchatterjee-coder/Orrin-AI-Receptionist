# Orrin - AI Voice Receptionist for Dental Clinics
Voice agent (Vapi) + n8n workflows + Cal.com + Google Sheets + RAG (Gemini).

Features: book, cancel and reschedule appointments by voice, and answer clinic FAQs using RAG.

Folders:
- n8n-workflows: exported n8n workflows
- vapi: system prompt and tool definitions
- web-demo: browser page to talk to Sarah (add your own keys in index.html)
